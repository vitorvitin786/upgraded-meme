# Meme Ascender

A tiny nostalgic internet-era idle/clicker game.

## Play

Open `index.html` in a browser. The game is fully self-contained: no build step, packages, or external assets.

### Quick phone preview

Because this repository is public, you can paste the GitHub `index.html` URL into an HTML preview service such as:

`https://html-preview.github.io/?url=https://github.com/vitorvitin786/upgraded-meme/blob/main/index.html`

For a permanent URL, enable GitHub Pages for the `main` branch from the repository's **Settings > Pages** section.

## Gameplay

- Post memes to earn Meme Bytes.
- Buy upgrades for stronger clicks and passive production.
- Progress through internet eras from the dial-up days to the post-ironic future.
- Ascending resets your run but awards Nostalgia, which permanently boosts production.
- Recover archive collectibles.
- Progress auto-saves in the browser with limited offline gains.

Built as one responsive HTML file so it works well on desktop and mobile.
